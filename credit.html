评审提示（本页为结构稿，数据均为示例，非真实行情）——请重点看结构与字段是否满足需求：
  1. 舆情分类体系：股权/资产划转、股东变更、增减资、融资环境、票据非标、评级、经营、财务、对外担保、管理层、其他负面——标签与利空/利好方向、高/中/低严重度是否合理？
  2. 排序规则：当日有变化主体标粗置顶（红色左条纹），无变化主体默认隐藏、可展开灰列；高估值成交 >5bp 加粗靠前——阈值 5bp 是否合适？
  3. 公告解读字段：公告类型 / 核心内容 / 信用影响分析 / 后续跟踪点，点评深度是否符合预期（正式版由 LLM 按点评 README 风格生成）？
  4. 估值成交口径：全部主体逐日覆盖——有成交的展示活跃券（当日成交量最大）成交收益率与偏离bp，无成交的仍展示中债估值 D1/D5/D20 变动；分组置顶：异常高估值(>5bp) → 低估值(<-5bp) → 估值变动大(D1≥5 或 D5≥10bp) → 正常；含权债剩余期限以行权日计、收益率均为行权口径，公司债标公募/私募，高收益阈值暂定 1.8%。
  5. 信评报告联动：偏离大(>5bp)或高收益(>1.8%)的主体须挂信评报告——主体名带 📎 可点击跳转（示例：西安高新控股）；无报告的标 ⚠待报告。报告由信评报告模板文件夹的 build_credit_report.py 生成，正式版随每日任务自动产出。
